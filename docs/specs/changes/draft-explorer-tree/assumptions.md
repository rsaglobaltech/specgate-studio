# Assumptions — draft-explorer-tree

What the brief does not say, chosen so the scenarios can be tested. Each is to
confirm by the person reviewing the draft. The look comes from
`docs/design/IDE.dc.html` and `docs/design/IDE-Cambios.dc.html`; the audit
that asked for it is `docs/design/conformance.md` ("Explorer and editor").
